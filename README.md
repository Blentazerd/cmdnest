# CmdNest

Минималистичный терминальный мультиплексор на Rust. Пишется с нуля как учебный проект и как личный удобный инструмент для терминала.

## Что уже умеет

- Запускает shell внутри собственного TUI
- Поддержка цветов и стилей (256 цветов + truecolor)
- Видимый мигающий курсор в правильной позиции
- Динамическое изменение размера PTY (SIGWINCH)
- **Сплит экрана**: несколько панелей в одном окне (дерево раскладки, как в tmux)
- **Вкладки (tabs)**: несколько независимых экранов с панелями
- **Прокрутка истории вывода (scrollback)** колесом мыши (размер настраивается)
- **Toggle mouse** (`Ctrl+B m`) — переключение между захватом мыши программой и нативным выделением текста
- **Клик мышью** по панели — переключение фокуса
- **Alt+стрелки** для быстрого переключения панелей
- **Префиксные горячие клавиши** в стиле tmux (`Ctrl+B`)
- **Конфигурация** через `~/.config/cmdnest/config.toml` (цвета, хоткеи, префикс, shell, размер истории)
- **Dirty-flag**: перерисовка только при изменениях — выделение текста мышью не сбрасывается без необходимости

## Требования

- Linux (разработано на Arch Linux, должно работать на любом дистрибутиве)
- Rust: `sudo pacman -S rust cargo` (или через [rustup](https://rustup.rs))

## Сборка и запуск

```bash
git clone https://github.com/Blentazerd/cmdnest.git
cd cmdnest
cargo run --release
Или собрать бинарник:

bash
cargo build --release
./target/release/CmdNest
Управление
Навигация
Alt+← / Alt+→ / Alt+↑ / Alt+↓ — переключение панелей напрямую

Ctrl+B, затем ← / → / ↑ / ↓ — то же через префикс

Клик левой кнопкой мыши по панели — переключение фокуса (когда Mouse:ON)

Управление панелями
Ctrl+B, затем % (или |) — вертикальный сплит активной панели

Ctrl+B, затем " (или -) — горизонтальный сплит активной панели

Ctrl+B, затем x — закрыть активную панель

Вкладки
Ctrl+B, затем c — новая вкладка

Ctrl+B, затем n — следующая вкладка

Ctrl+B, затем p — предыдущая вкладка

Ctrl+B, затем & — закрыть активную вкладку

Прокрутка
Колесо мыши вверх/вниз — прокрутка истории активной панели (когда Mouse:ON)

Размер истории настраивается в конфиге (scrollback_lines, по умолчанию 1000 строк)

При прокрутке вверх курсор ввода скрывается (показывает, что вы не в живом режиме)

Прокрутите вниз до конца — вернётесь к живому выводу

Мышь
Ctrl+B, затем m — toggle mouse:

Mouse: ON (по умолчанию) — клики и колесо идут в программу, выделение текста — только через Shift+протяжку

Mouse: OFF — терминал сам обрабатывает мышь, работает нативное выделение текста

В статус-баре всегда видно текущее состояние: Mouse:ON или Mouse:OFF

Совет: если в режиме Mouse:ON нужно выделить текст, но Shift+протяжка не работает в вашем терминале — переключитесь в Mouse:OFF (Ctrl+B m), выделите, скопируйте, верните обратно (Ctrl+B m).

Выход
Ctrl+Q — выход из программы (все панели закрываются, все PTY-процессы убиваются)

Конфигурация
Файл: ~/.config/cmdnest/config.toml. Создаётся автоматически при первом запуске с дефолтными значениями. После изменения файла — перезапустите CmdNest.

Пример:

toml
[general]
prefix = "C-b"              # C-a, M-x, b — что угодно
scrollback_lines = 1000     # сколько строк истории
shell = "/bin/zsh"          # если не задан — берётся из $SHELL

[keys]
split_vertical = "%"
split_horizontal = "\""
new_tab = "c"
next_tab = "n"
prev_tab = "p"
close_tab = "&"
close_pane = "x"
toggle_mouse = "m"

[colors]
border_focused = "cyan"
border_unfocused = "darkgray"
status_bg = "cyan"
status_fg = "black"
Формат хоткеев
Префикс: "C-b" (Ctrl+B), "M-x" (Alt+X), "b" (просто B)

Клавиши после префикса: один символ ("%", "c", "x" и т.д.)

Модификаторы: C- = Ctrl, M- = Alt, S- = Shift

Доступные цвета
black, red, green, yellow, blue, magenta, cyan, gray, darkgray, white, reset

Поведение при ошибках в конфиге
Файла нет → создаётся дефолтный, программа работает с ним

Файл битый → выводится сообщение в stderr, программа работает с дефолтными значениями

Программа никогда не падает из-за конфига

Архитектура
Проект разбит на модули:

text
src/
├── main.rs      — точка входа, event loop, dirty-flag
├── app.rs       — состояние (вкладки, панели, префикс, мышь), обработка событий
├── pane.rs      — одна панель (PTY, парсер vt100, scrollback)
├── layout.rs    — дерево раскладки (вложенные сплиты)
├── ui.rs        — вся отрисовка (рендер панелей, статус-бар)
└── config.rs    — парсинг TOML-конфига, ключи, цвета
Известные ограничения
Выделение мышью может сбрасываться при активном выводе в панели (shell с часами в PS1, htop в другой панели, фоновые процессы). Решение — copy mode (в разработке) или sleep 100 в панели для «заморозки».

Нет copy mode — для выделения и копирования из scrollback используйте toggle mouse + нативное выделение терминала.

Нет detach/attach — сессия живёт, пока CmdNest запущен. При выходе все процессы убиваются.

Сплиты фиксированного размера — все делятся 50/50. Resize панелей в разработке.

Только Linux — Windows и macOS не тестировались (portable-pty их поддерживает, но код не адаптирован).
